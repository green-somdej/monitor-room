## ✨ ภาพรวม

เว็บแอปที่ทำงานบน **Google Apps Script** ใช้ **Google Sheets** เป็นฐานข้อมูล และ **Google Drive** เก็บภาพถ่าย
ไม่ต้องมีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่ายโครงสร้างพื้นฐาน ผู้ดูแลแก้ไขข้อมูลหลักได้จากชีตโดยไม่ต้องแตะโค้ด

| โมดูล | สิ่งที่ทำได้ |
|---|---|
| 🌱 **ประเมินสิ่งแวดล้อม** | บันทึกคะแนนรายหน่วยงาน/เดือน คำนวณร้อยละและระดับผล (ดีเยี่ยม / ดี / พอใช้ / ต้องแก้ไข) พร้อมอีเมลยืนยัน |
| 🧹 **ติดตามกิจกรรม 5ส** | บันทึกปัญหาตามพื้นที่ ติดตามความคืบหน้า แนบภาพหลังแก้ไข |
| 🗑️ **ตรวจถังขยะ** *(ใหม่)* | บันทึกจำนวนถังที่ตรวจ/พบทิ้งผิด พร้อมรายละเอียด และสถิติอัตราทิ้งถูกต้อง |
| 📸 **แจ้งปัญหาขยะ** | แจ้งพร้อมภาพ กำหนดแก้ไขภายใน 12 ชม. เตือนอัตโนมัติเมื่อใกล้/เกินกำหนด |
| 📊 **แดชบอร์ดและรายงาน** | สรุปภาพรวมรายเดือน/ปี รายงานผู้บริหารพิมพ์เป็น PDF รายงานขยะรายวัน/สัปดาห์/เดือน |
| 🔗 **ลิงก์แชร์รายหน่วยงาน** | แต่ละหน่วยงานดูผลและบันทึกการแก้ไขของตนเองได้ผ่านลิงก์เดียว |

## 🗑️ โมดูลตรวจถังขยะ (ใหม่)

บันทึกผลการตรวจรายจุด เพื่อวัด **อัตราการคัดแยกขยะถูกต้อง** และชี้เป้าหน่วยงาน/ชั้นที่ต้องปรับปรุง

**ตัวอย่างการบันทึก**

| ช่อง | ตัวอย่าง |
|---|---|
| หน่วยงาน / พื้นที่ | หอผู้ป่วยใน 5 |
| อาคาร | อาคารอนุสรณ์ ๑๐๐ ปี |
| ชั้น | 5 |
| จำนวนถังที่ตรวจ | 5 |
| พบการทิ้งผิด | 2 |
| รายละเอียด | พบที่ห้องพักเจ้าหน้าที่ ทิ้งเปลือกกล้วยในถังขยะทั่วไป |

→ ระบบคำนวณ **ทิ้งถูกต้อง 60% (3 จาก 5 ถัง)** ให้ทันทีขณะกรอก

**ความสามารถ**
- ตรวจสอบข้อมูล: ถังที่พบผิดต้องไม่เกินถังที่ตรวจ, ต้องระบุรายละเอียดเมื่อพบการทิ้งผิด, วันที่ตรวจห้ามเป็นอนาคต
- ตรวจจุดถัดไปได้เร็ว: หลังบันทึก ระบบคงหน่วยงาน/อาคาร/ชั้นไว้ให้
- **สถิติ**: ตัวเลขรวม (KPI), จัดอันดับตามหน่วยงาน (เรียงจากต่ำสุด), ตามอาคาร/ชั้น, ตามวัน, และรายการล่าสุดพร้อมรายละเอียด
- เกณฑ์สี: 🔵 ≥ 95% · 🟡 80–94% · 🔴 < 80%
- ลิงก์รายหน่วยงานแสดงเฉพาะข้อมูลของหน่วยงานนั้น และไม่เปิดเผยชื่อผู้ตรวจ

ข้อมูลเก็บในชีต **`ตรวจถังขยะ`** (สร้างอัตโนมัติ) สามารถนำไปทำ Pivot/กราฟต่อได้

## 🚀 การติดตั้ง

1. สร้าง Google Sheet ที่มีชีตหน่วยงาน (`หน่วยงาน`), `บันทึกข้อมูล`, `ติดตาม5ส`
2. เปิด **ส่วนขยาย → Apps Script** แล้วคัดลอกไฟล์ `.gs` และ `.html` ในโปรเจกต์นี้เข้าไป
3. เรียกใช้ฟังก์ชัน `setupWasteSystem` **หนึ่งครั้ง** เพื่อสร้างชีตขยะ (รวม `ตรวจถังขยะ`) และตั้งเวลาทำงานรายชั่วโมง
4. **ทำให้ใช้งานได้ → เว็บแอป** แล้วเปิดใช้งาน
5. กรอกอีเมลผู้รับแจ้งในชีต `ผู้รับแจ้งขยะ` และรายชื่ออาคารในชีต `อาคาร`

## 🏠 ลิงก์เดียว · หน้าหลักแบบการ์ด

ผู้ใช้จำ **ลิงก์เดียว** (GitHub Pages หรือ URL เว็บแอป) แล้วเลือกกิจกรรมจากการ์ด ทุกหน้ามีปุ่ม ← กลับหน้าหลัก

| บันทึกและติดตามงาน | รายงานและวิเคราะห์ |
|---|---|
| ประเมินสิ่งแวดล้อม · ติดตามกิจกรรม 5ส · ตรวจถังขยะ · แจ้งปัญหาขยะ · ติดตามและบันทึกการแก้ไขขยะ | สรุปภาพรวม · แดชบอร์ดรายหน่วยงาน · สถิติการตรวจถังขยะ · รายงานการจัดการขยะ · รายงานผู้บริหาร · ลิงก์แชร์รายหน่วยงาน |

**GitHub Pages:** `index.html` เปิดเว็บแอปเต็มจอ ผู้ดูแลแก้ค่า `WEBAPP_URL` (URL ที่ลงท้าย `/exec`) ในไฟล์นี้ครั้งเดียว

*(ไม่บังคับ)* ลิงก์ตรงเข้ากิจกรรม: `?tab=env|5s|bin|wform|wboard|summary|dash|wstats|wreport|exec|share`

## 🔗 ลิงก์อื่นของระบบ

| หน้า | พารามิเตอร์ |
|---|---|
| ตรวจถังขยะ | `?page=waste&tab=bin` |
| สถิติการตรวจถัง | `?page=waste&tab=stats` |
| แจ้ง/ติดตามปัญหาขยะ | `?page=waste&tab=form` · `?page=waste&tab=board` |
| รายงานขยะพิมพ์/แชร์ | `?page=wastereport&period=day\|week\|month` |
| สรุปภาพรวม | `?page=summary&view=month\|year` |
| รายงานผู้บริหาร | `?page=report&topic=both&period=month` |
| รายหน่วยงาน | `?page=dept&dept=<ชื่อหน่วยงาน>` |

## 🔒 ความเป็นส่วนตัวและความปลอดภัย

- ลิงก์แชร์สาธารณะ **ไม่ส่งชื่อ/อีเมลบุคคล** ออกไปยังหน้าเว็บ
- ข้อความที่ขึ้นต้นด้วย `= + - @` ถูกป้องกันไม่ให้ Sheet ตีความเป็นสูตร
- ข้อมูลทุกช่องถูก escape ก่อนแสดงผล และใช้ Lock ป้องกันรหัสซ้ำเมื่อบันทึกพร้อมกัน
- ภาพถ่ายต้องไม่เห็นผู้ป่วยหรือข้อมูลผู้ป่วย
